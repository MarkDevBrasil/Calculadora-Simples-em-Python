🧮 Python Calculator

Uma calculadora simples feita em Python para praticar lógica de programação e operações matemáticas.

🚀 Funcionalidades

✔️ Soma
✔️ Subtração
✔️ Multiplicação
✔️ Divisão

🛠️ Tecnologias
Python 3
▶️ Como executar
git clone https://github.com/SEU-USUARIO/python-calculator.git
cd python-calculator
python calculadora.py

📷 Exemplo
Digite um numero: 10
Digite outro numero: 5

Qual a operação que deseja realizar?
(soma, subtração, multiplicação ou divisão): soma

O resultado da soma é: 15
